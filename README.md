App Controle Remoto
🎯 Objetivo
A resolução de desafios de conectividade entre dispositivos móveis e hardware é essencial para o desenvolvimento de ecossistemas interativos eficientes e escaláveis. Este projeto consiste em uma interface móvel para o controle remoto de um carrinho via Bluetooth, eliminando fios através de comandos intuitivos e ágeis. A solução resolve a necessidade de uma navegação sem fio estável, integrando o software ao hardware de forma eficiente para garantir total mobilidade. Esta estrutura de comando direta e simplificada define a base técnica para a execução de todas as funcionalidades práticas presentes no aplicativo. Essa clareza de propósito orientou cada decisão técnica e funcionalidade implementada, garantindo que a execução técnica atenda perfeitamente à proposta prática de controle sem fio.
✨ Funcionalidades
Conexão Bluetooth: Garante a mobilidade indispensável ao projeto, estabelecendo o enlace de comunicação sem fio necessário para a operação à distância entre o smartphone e o hardware.
Controles Direcionais: Proporcionam movimentos precisos e intuitivos, traduzindo o toque na tela em uma resposta física imediata e exata por parte do carrinho para uma usabilidade superior.
Parada Rápida: Atua como um mecanismo de segurança crítico, permitindo a interrupção instantânea dos motores para evitar colisões e danos ao equipamento durante o uso.
🛠️ Tecnologias Utilizadas
MIT App Inventor: Plataforma central utilizada para a criação da interface visual e da lógica de controle baseada em blocos, permitindo o desenvolvimento ágil de sistemas complexos.
GitHub e Git: O GitHub atua como o pilar do portfólio profissional e ambiente de colaboração, permitindo que equipes trabalhem simultaneamente no mesmo código sem conflitos. O sistema Git opera como uma "máquina do tempo", preservando o histórico completo de alterações e garantindo a integridade de arquivos como o .aia (o código-fonte da lógica de blocos) e o .apk (o binário executável pronto para instalação).
## 📂 Como testar este aplicativo?
1. Baixe o arquivo `.aia` disponível neste repositório.
2. Acesse o [MIT App Inventor](http://ai2.appinventor.mit.edu/).
3. Clique em **Projetos > Importar projeto (.aia) do meu computador**.
4. Selecione o arquivo baixado para visualizar e testar o código!
